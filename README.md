# 🎓 Student Management System (Java + MySQL)

The **Student Management System** is a desktop-based application developed using **Java** and **MySQL** to simplify and automate the management of student records. This project demonstrates the integration of Java with a relational database using **JDBC**, providing a practical implementation of CRUD (Create, Read, Update, Delete) operations while following clean coding practices.

The primary objective of this project is to replace the traditional manual method of maintaining student information with a secure, efficient, and user-friendly system. It allows users to store, retrieve, update, search, and delete student records through an organized interface connected to a MySQL database.

The application is designed with a modular architecture, making the code easy to understand, maintain, and extend. By separating database connectivity, business logic, and user interaction, the project follows good software development practices and serves as an excellent learning resource for beginners exploring Java database applications.

## ✨ Features

* ➕ Add new student records
* 📋 View all students stored in the database
* 🔍 Search students using their unique ID

* 💾 MySQL database integration using JDBC
